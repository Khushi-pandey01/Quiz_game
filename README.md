# 🧠 Interactive Quiz Challenge

A complete terminal-based interactive quiz application built using Python. 
This project tests users on general knowledge and core programming concepts, featuring a score tracking system, score percentage calculation, and a replay feature.

## 🚀 Features
* **Diverse Question Bank:** Tests users on general awareness and Python fundamentals.
* **Smart Validation:** Handles case-insensitive inputs (e.g., accepting 'pacific', 'Pacific', or 'PACIFIC').
* **2-Chance Retry System:** Users get exactly one more chance to correct a wrong answer before moving forward.
* **Smart Answer Revealer:** If a user gets the answer wrong on both attempts, the program automatically reveals the correct answer so they can learn from it.
* **Performance Summary:** Calculates and displays the final score along with the performance percentage and a custom ranking message.
* **Play Again Feature:** Includes an interactive replay loop that validates inputs (`Y`/`N`) and lets the user restart the quiz smoothly.

## 🛠️ Tech Stack
* **Language:** Python 3

## 💻 How to Run
1. Clone this repository or download the source code.
2. Open your terminal or VS Code.
3. Run the following command:
   ```bash
   python Quiz_Game.py
   ```
